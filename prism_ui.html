FRAMEWORK OVERVIEW

Prism UI est un framework C++ pour l'UMG d'Unreal Engine 5.7, conçu pour être strictement zero-tick (piloté par événements), orienté données (tokens sémantiques) et rapide à utiliser pour un programmeur via une approche Fluent Builder. Il remplace les couleurs et polices codées en dur dans chaque widget, le Tick() permanent pour les transitions visuelles, et le churn GC lié à la création/destruction constante de widgets.

MODULE: THEMING

THEMING PAR TOKENS SÉMANTIQUES

  • > Moteur central : UPrismUIThemeSubsystem (LocalPlayerSubsystem) tient le thème actif et notifie tous les widgets abonnés lors d'un changement.
  • > Tokens sémantiques : EPrismColorToken / EPrismTypographyToken mappés par "rôle" de widget (Primary, Danger...) via des Data Assets (UPrismUIThemeData, UPrismUIStyle).
  • > Reskin instantané : changer le thème actif re-skinne toute l'UI à l'exécution, sans toucher au code — un mode sombre alternatif devient un simple asset de données.
[ THEME_SUBSYSTEM → ROLE → STYLE ]

ZERO-TICK & WIDGET POOLING

UPrismWidgetBase est la base commune de tout widget Prism : machine à états (EPrismWidgetState), transitions visuelles pilotées par timer, et nettoyage automatique des bindings et du pool à la destruction.

TICK

ZERO-TICK BASE

EVENT-DRIVEN
  • Transitions minutées : StartVisualTransition ne s'exécute que le temps de l'animation, puis se désenregistre.
  • État explicite : Normal / Hovered / Pressed / Disabled / Selected géré par une seule machine à états.
POOL

WIDGET POOLING

GC-SAFE
  • Pool par classe : UPrismUIWidgetPoolSubsystem évite le churn GC des listes et éléments de HUD.
  • Cycle de vie : tout widget Prism implémente IPrismPoolableWidget pour se nettoyer proprement quand il retourne au pool.
BIND

DATA BINDING

REACTIVE
  • IPrismUIDataBound : interface générique BindData(UObject*) pour tout widget piloté par des données.
  • Nettoyage auto : chaque binding s'enregistre via AddBindingCleanup et se coupe automatiquement à la destruction/mise en pool.
MODULE: BUILDER

FLUENT C++ BUILDER & MACROS

  • > API chaînable : FPrismBuilder (inspiré de Slate / des frameworks web) construit des arbres UMG en quelques lignes : BeginVerticalBox / AddText / SetPadding / EndPanel.
  • > Binding réactif : .BindEvent() templaté relie un delegate à une lambda, avec nettoyage automatique via un flag "actif" partagé — pas de fuite de lambda après destruction.
  • > Macros complémentaires : PRISM_CREATE, PRISM_ADD_VBOX/HBOX/OVERLAY pour une construction UMG typée sans passer par le Widget Designer. 
// FPrismBuilder usage
Builder.BeginVerticalBox()
    .AddText(TEXT("Score"), "Primary", H2)
    .AddButton("Primary")
        .BindEvent(OnClicked, [this]{ Fire(); })
    .EndPanel();

BIBLIOTHÈQUE DE WIDGETS

Boutons, toggles, sliders, dropdowns et search box thémés composent la base ; deux composants sortent du lot par leur complexité.

[ COLOR_WHEEL / RADIAL_MENU ]

> COMPOSANTS AVANCÉS

  • UPrismColorWheel : sélecteur de couleur circulaire HSV, sélection Teinte/Saturation en un seul espace 2D, drag input natif.
  • UPrismRadialMenu : menu radial segmenté (pie menu) pour une sélection rapide, pensé manette.
  • UPrismUIModelWidget : aperçu 3D d'un mesh statique ou skeletal (avec animation) rendu vers une RenderTarget via SceneCaptureComponent2D, avec rotation au drag et zoom molette.

BONUS : SIMULATEUR LIVE-PREVIEW

> HOT-RELOAD SANS ÉDITEUR

Tools/Simulator est un outil de développement indépendant de l'éditeur Unreal : un serveur Node.js qui surveille le dossier Source/PrismUI, parse le C++ modifié par regex, et pousse en direct (Server-Sent Events) une reconstruction approximative de l'arbre de widgets dans un navigateur.

  • Parsing statique : extraction des NewObject/CreateWidget/PRISM_CREATE, des SetXxx(...) et de la hiérarchie AddChildTo* directement depuis le texte source.
  • Feedback instantané : un programmeur modifie BuildDefaultLayout() en C++ et voit le résultat approximatif dans l'onglet navigateur, sans recompiler ni relancer l'éditeur.
