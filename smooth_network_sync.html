SMOOTH NETWORK SYNC

ADVANCED MOVEMENT REPLICATION // UNREAL ENGINE 5.7

TYPE UNREAL PLUGIN
FOCUS MOVEMENT SYNC
NETWORKING REPLICATED

SYSTEM OVERVIEW

Smooth Network Sync remplace/complète la réplication de mouvement native d'Unreal Engine 5.7. Il synchronise transform (position, rotation, échelle) et vélocité pour les Simulated Proxies comme pour les Autonomous Proxies, pour des pawns/personnages comme pour des props (y compris physiques).

CŒUR D'INTERPOLATION

UNetworkInterpolatorComponent tient deux buffers circulaires d'états horodatés (position / rotation). USmoothSyncSubsystem, un UTickableWorldSubsystem central, évalue chaque frame la position interpolée de chaque composant enregistré.

LERP

INTERPOLATION

HERMITE SLERP
  • Position : spline cubique Hermite entre deux états bufferisés, tangentes dérivées de la vélocité.
  • Rotation : FQuat::Slerp entre les états bufferisés.
SNAP

EXTRAPOLATION & HARD-SNAP

DEAD RECKONING
  • Dead reckoning : position + vélocité, plafonné par MaxExtrapolationTime en cas de paquets perdus.
  • Téléportation : au-delà d'un seuil de distance, snap direct sans interpolation (évite de traverser les murs).
JIT

JITTER BUFFER & LOD RÉSEAU

ADAPTIVE
  • Buffer dynamique : le délai d'interpolation cible s'ajuste selon la santé du buffer (0.10s à 0.15s), lissé par FInterpTo.
  • Network LOD : fréquence de mise à jour position/rotation réduite selon la distance au joueur local (pleine fréquence, 10Hz, 5Hz).
MODULE: PREDICTION

PRÉDICTION CLIENT (AUTONOMOUS PROXY)

  • > Correction ressort-amortisseur : HandleAutonomousProxyPrediction compare la position locale prédite à la position extrapolée par le serveur, et applique une accélération de correction proportionnelle et bornée.
  • > Physique et non-physique : fonctionne aussi bien pour des acteurs qui simulent la physique que pour des pawns classiques, avec un amortissement supplémentaire sur l'axe Z.
  • > Snap dur / doux : correction angulaire douce sous un seuil, snap dur au-delà — pour ne jamais laisser le joueur "glisser" visiblement vers la bonne position.
[ LOCAL PREDICTION vs SERVER STATE ]

OPTIMISATION DE LA BANDE PASSANTE

> COMPRESSION RÉSEAU CUSTOM

Les états répliqués implémentent leur propre NetSerialize plutôt que de s'appuyer sur la réplication par défaut.

  • Position/scale : quantifiées via FVector_NetQuantize100.
  • Rotation : quaternion compressé "à trois composantes" — le W est abandonné et reconstruit depuis X/Y/Z, chacun packé sur 16 bits.
  • Tolérance de changement : les mises à jour redondantes (sous un seuil de position/rotation/échelle) ne sont pas envoyées.
[ QUAT (X,Y,Z) → 16-BIT PACKED ]

USAGE : ACTEURS D'EXEMPLE

Le plugin fournit un mode client-authoritative optionnel (bIsClientAuthoritative) et quatre acteurs d'exemple implémentant l'interface ISmoothSyncable : SmoothPawn (Character + Enhanced Input), SmoothProp, SmoothPhysicsProp et SmoothScaleProp.
