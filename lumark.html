PLATFORM ANDROID / iOS

PRÉSENTATION

LuMark est une application mobile professionnelle développée en Qt 6 / QML / C++ pour les métreurs du bâtiment (menuiserie Alu/PVC/Bois). Elle transforme un laser Bluetooth du commerce en outil de métré numérique : prise de cotes sur site, comparaison en temps réel aux tolérances d'un gabarit technique, et génération de rapports de conformité PDF. Projet solo, actuellement en production avec plus de 50 commits, doté d'un système de licence commerciale complet.

ARCHITECTURE

MVVM & REPOSITORY PATTERN

  • > Séparation stricte :

    le QML (View) n'a aucune logique métier.
    Cinq ViewModels C++ (AppViewModel, ProjectViewModel, DrawingViewModel, MarkerViewModel, ExportViewModel) exposent l'état via Q_PROPERTY/Q_INVOKABLE.
  • > Repository Pattern :

    IDataRepository découple la logique métier du stockage.
    Aujourd'hui, c'est SqliteRepository qui l'implémente.
    Demain, un RestApiRepository pourra s'y brancher pour la synchronisation ERP — sans toucher au reste du code.
  • > Modèle multi-métier :

    ProfessionManager et TemplateManager décrivent cotes et tolérances par métier via des schémas JSON dynamiques, plutôt que des colonnes SQL figées.
View (QML) → ViewModel (C++) → IDataRepository → SqliteRepository

ABSTRACTION MATÉRIELLE : LASERS BLUETOOTH

Aucune marque de laser n'est câblée en dur dans l'application. ILaserDevice définit un contrat commun ; AbstractBleLaserDevice porte le moteur BLE générique, chaque marque ne surcharge que le décodage de trame.

BLE

MOTEUR BLE GÉNÉRIQUE

QLOWENERGY
  • Découverte GATT :

    filtrage par nom, connexion prioritaire aux appareils déjà appairés, activation en file des descriptors Notify/Indicate.
  • Workaround Android :

    requête JNI des appareils déjà "bonded" (BluetoothAdapter.getBondedDevices) via QtConcurrent, car le scan BLE standard les ignore souvent.
DECODE

DÉCODAGE PAR MARQUE

LEICA / HILTI
  • Leica Disto :

    tentative de décodage binaire IEEE-754, repli sur un parsing texte par regex si la trame binaire est invalide.
  • Hilti PD-I :

    décodage texte par regex. Ajouter une nouvelle marque = une classe de plus, sans toucher au reste.
PERM

PERMISSIONS & SERVICE

HARDWARESERVICE
  • Façade QML :

    HardwareService expose connexion/état/dernière mesure, et instancie le bon device via LaserFactory.
  • Permissions runtime :

    machine à états gérant les permissions Bluetooth/localisation Android avant toute connexion.
MODULE: QA / DXF

GABARITS DXF & CONTRÔLE DE CONFORMITÉ

  • > Parser DXF maison :

    DxfParser convertit les entités LINE/LWPOLYLINE/ARC d'un plan AutoCAD en chemin SVG, et extrait les cotes (TEXT/MTEXT) comme points de mesure ciblés.
  • > Bibliothèque de formes :

    DxfManager gère l'import et le stockage local des gabarits, avec repositionnement manuel des étiquettes de cote.
  • > Jauge de tolérance temps réel :

    chaque cote a une valeur cible et une tolérance ; la mesure laser reçue est comparée en direct, avec code couleur (orange/vert/rouge) sur le marqueur du plan.
DXF (LINE/ARC) → SVG PATH → TOLERANCE GAUGE

RAPPORTS DE CONFORMITÉ PDF

[ GABARIT + COTES RÉELLES + PHOTOS ]

> STRATEGY PATTERN (IPdfRenderer)

ExportViewModel::GeneratePdfReport assemble un rapport client vectoriel via QPainter, combinant plans, diagrammes de cotes et preuves photo.

  • Double diagramme :

    DrawGabaritDiagram (cotes théoriques + tolérances) et DrawMeasurementDiagram (cotes réelles relevées).
  • Options client :

    inclusion des plans, tolérances, repères et photos, à la carte pour chaque rapport généré.
  • Partage natif :

    ouverture/partage du PDF via l'Intent Android natif (FileProvider).
MODULE: COMMERCIAL

SYSTÈME DE LICENCE COMMERCIALE

  • > Vérification signée RSA :

    LicenseManager interroge un serveur Node/Express dédié, vérifie la signature de la réponse via OpenSSL (SHA-256), et met le résultat en cache localement.
  • > Fonctionnement hors-ligne :

    grâce au cache signé, la licence reste valide 7 jours sans connexion, avec détection de recul d'horloge système pour éviter la triche.
  • > Stockage sécurisé :

    SecureStorage chiffre le cache de licence (DPAPI sous Windows, AES-256 OpenSSL sur les autres plateformes) et lie la licence à l'appareil.
[ CLIENT → SIGNED LICENSE SERVER → OFFLINE CACHE ]

PARCOURS UTILISATEUR

Licence → Chantier → Repérage (cotes/tolérances/gabarit DXF) → Plan PDF avec repères → Mesure au laser en direct avec jauge de tolérance et photo → Export du rapport PDF.
